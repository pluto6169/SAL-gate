# SAL Gate: الفكرة

> بوابة معرفية أكاديمية واحدة تجمع المفاهيم وتعريفاتها ومراجعها وعلاقاتها، وكل معلومة فيها مربوطة بمصدرها.

---

## 1. ما هو SAL Gate؟

SAL Gate **موقع واحد** فوق **قاعدة معرفة واحدة**، يعرض المحتوى نفسه بثماني طرق مختلفة. المحتوى لا يتكرر: المفهوم يُكتب مرة واحدة، ثم يظهر في المعجم والشجرة والخريطة والبحث والمساعد.

**الفكرة المركزية:** المعرفة تُنظَّم على ثلاث طبقات تتكامل مع بعضها، وكل معلومة تحمل مصدرها معها.

---

## 2. المبادئ

| المبدأ | معناه |
|---|---|
| **بساطة البناء** | موقع واحد، قاعدة بيانات واحدة، ثلاث تقنيات فقط. |
| **التوثيق أولًا** | لا يوجد تعريف بلا مصدر وتاريخ مراجعة وترخيص (Provenance). |
| **تعدد اللغات** | العربية والإنجليزية والفرنسية في كل شيء: المحتوى والتصفح والبحث. |
| **مصدر واحد للحقيقة** | الشجرة والخريطة والبحث تقرأ من نفس الجداول. |
| **النمو التدريجي** | نبني الأساس أولًا، ونضيف الأقسام على نفس القاعدة. |
| **الصدق المعرفي** | المساعد لا يجيب عمّا ليس في القاعدة. |

---

## 3. ثلاث طبقات لتنظيم المعرفة

### التاكسونومي (Taxonomy): التسلسل الهرمي
كل مفهوم له **أعمّ** منه و**أخصّ**. مثال: المعرفة ← تنظيم المعرفة ← التصنيف ← المكنز.
يظهر في **SAL Tree** كشجرة فعلية بفروع قابلة للفتح والإغلاق.

### الأنطولوجيا (Ontology): العلاقات المحددة النوع
- لكل مفهوم **صنف** (مجال، عملية، أداة، بيانات، مبدأ).
- العلاقات بين المفاهيم **لها أنواع** ولا تقتصر على «مرتبط بـ»: جزء من، يُستخدم في، يدعم، يمهّد لـ…
يظهر في **SAL Atlas** كشبكة ملوّنة حسب الصنف والعلاقة.

### الفولكسونومي (Folksonomy): وسوم القرّاء
وسوم حرة يضيفها القرّاء بكلماتهم ولغاتهم، وتكبر بكثرة الاستخدام. تكشف كيف يفكّر الناس في المفهوم، وتغطي ما لا تغطيه المصطلحات الرسمية.
يظهر في **SAL Tags** كسحابة وسوم، وهي أيضًا جزء من البحث.

> الرسمي (تاكسونومي وأنطولوجيا) يُحرَّر ويُراجَع. الشعبي (فولكسونومي) يأتي من القرّاء. وجودهما معًا يعطي دقة المتخصصين وتنوع المستخدمين.

## 4. الأقسام الثمانية

| القسم | الوظيفة |
|---|---|
| **SAL Glossary** (المعجم) | المفاهيم وتعريفاتها بثلاث لغات، وكل تعريف له مصدر. |
| **SAL Tree** (شجرة المعرفة) | التاكسونومي: الفروع من الأعم إلى الأخص. |
| **SAL Atlas** (العلاقات) | الأنطولوجيا: شبكة علاقات وأصناف. |
| **SAL Library** (المراجع) | الكتب والوثائق، وبياناتها وترخيصها وكيفية الوصول إليها. |
| **SAL Search** (البحث) | بحث بالعربية والإنجليزية والفرنسية معًا، يشمل الوسوم، مع تطبيع عربي. |
| **SAL RAG** (المساعد) | يسترجع المقاطع المعتمدة ثم يصوغ إجابة موثّقة بمصدرها. |
| **SAL Lingua** (اللغات) | تبديل لغة الموقع كله. |
| **SAL Tags** (الوسوم) | الفولكسونومي: إضافة وتصفح الوسوم. |

*(قسم SAL Open للبيانات المفتوحة تقرّر حذفه من النسخة الحالية.)*

## 5. البناء التقني

**Modular Monolith:** موقع واحد، وخادم واحد، وقاعدة بيانات واحدة.

| التقنية | الاستخدام |
|---|---|
| HTML + CSS + JavaScript | الواجهة |
| Python | الخادم ومعالجة البيانات |
| SQLite | البيانات والبحث والعلاقات |

لا نبدأ بـ React أو Node.js أو PostgreSQL أو Docker أو Elasticsearch أو Redis أو Microservices. تُضاف أي مكتبة فقط عند ظهور ضرورة فعلية.

## 6. قاعدة البيانات

الجداول السبعة الأصلية:

| الجدول | الوظيفة |
|---|---|
| `concepts` | المفاهيم |
| `labels` | الأسماء بمختلف اللغات |
| `statements` | التعريفات والشروح والأمثلة |
| `relations` | العلاقات والشجرة |
| `agents` | المؤلفون والمؤسسات |
| `sources` | المراجع والوثائق |
| `statement_sources` | ربط كل تعريف بمراجعه |

**إضافات أقترحها لتغطية الطبقات الثلاث:**

- في `concepts`: حقل `class` (صنف المفهوم، للأنطولوجيا).
- في `relations`: حقل `type` (broader/narrower، part_of، used_in، supports، precedes…).
- جدول جديد `tags`: `concept_id`، `tag`، `lang`، `count` (للفولكسونومي).

التراخيص وتواريخ المراجعة تُخزَّن كحقول في البداية، وتُفصل في جداول مستقلة عند الحاجة.

## 7. المساعد (SAL RAG)

1. يستقبل السؤال بأي لغة من الثلاث.
2. يسترجع المقاطع من المحتوى المعتمد فقط.
3. يرسلها إلى نموذج لغوي ليصوغ الإجابة، مع ذكر المصادر.
4. إن لم يجد المعلومة يقول ذلك صراحةً ولا يخمّن.

هذا القسم الوحيد الذي يحتاج ربط نموذج ذكاء اصطناعي، ولا حاجة لتنزيل نموذج على الجهاز.

---

## 8. مراحل التنفيذ

1. **Foundation:** قاعدة البيانات، المعرفات، اللغات، المصادر، العلاقات.
2. **Glossary + Tree:** الجزءان الأهم، ويُبنيان أولًا.
3. **Library + Atlas:** المراجع والربط البصري.
4. **Search + Lingua + Tags:** البحث متعدد اللغات والوسوم.
5. **RAG:** المساعد المعرفي.

الهدف الأول: **SAL Gate Foundation 1.0** بقاعدة البيانات والواجهة الرئيسية والمعجم والشجرة شغّالين فعليًا.

---

## 9. ما لن نبنيه من البداية

- محرك بحث دلالي متطور قبل وجود محتوى كافٍ.
- ترجمة آلية كاملة لكل المصطلحات.
- مساعد يجيب عمّا ليس في القاعدة.
- نظام مستخدمين وصلاحيات ضخم قبل الحاجة إليه.

---

## 10. الشكل والتجربة

- واجهة أكاديمية حديثة، هادئة، تدعم الاتجاهين (RTL وLTR) والوضع الداكن.
- صفحة رئيسية تشرح الموقع، وتتيح الوصول لأي قسم بنقرة.
- بطاقة المفهوم هي الوحدة المشتركة بين الأقسام: الأسماء، الصنف، التعريف، مسار الشجرة، المصادر، العلاقات، الوسوم.
- الديمو الحالي ملف واحد ببيانات تجريبية، وشكل بياناته مطابق للجداول أعلاه.

---

## 11. نقاط مفتوحة

- **شكل خريطة العلاقات:** هل تبقى شبكة تفاعلية، أم تتحول إلى خريطة ذهنية أو جدول علاقات؟
- **مصدر الوسوم:** هل يضيفها الجميع، أم بعد مراجعة؟
- **أنواع العلاقات النهائية:** القائمة الحالية تجريبية وتحتاج مراجعة متخصصين.
- **أصناف المفاهيم:** الأصناف الخمسة الحالية تجريبية أيضًا.
